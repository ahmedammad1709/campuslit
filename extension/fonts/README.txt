This unchanged font asset was sourced from an existing local Inter distribution
because external shell downloads were unavailable. Its font-family and loaded
status were checked in the browser. No external font provider is contacted.

Plus Jakarta Sans, Manrope and Sora (Latin variable subsets) are bundled locally from the
@fontsource-variable packages on npm. All are SIL OFL 1.1 licensed (OFL-PlusJakartaManropeSora.txt).
